# Bandit Level 0 → Level 1

**Сложность:** ⭐ (1/5)  
**Тема:** Первое SSH-подключение  
**Инструменты:** `ssh`, `ls`, `cat`

---

## 📋 Описание задания

> *Цель этого уровня — войти в игру по SSH. Для подключения используйте хост bandit.labs.overthewire.org, порт 2220. Имя пользователя — bandit0, пароль — bandit0. После входа в систему перейдите на страницу Уровня 1, чтобы узнать, как пройти этот уровень.*

**Задача:** Подключиться к серверу и найти пароль для следующего уровня (`bandit1`).

---

## 🔍 Разведка

### Данные для подключения:
- **Хост:** `bandit.labs.overthewire.org`
- **Порт:** `2220`
- **Пользователь:** `bandit0`
- **Пароль:** `bandit0`

---

## ⚔️ Решение

### Шаг 1: Подключение по SSH

```bash
ssh bandit0@bandit.labs.overthewire.org -p 2220
При запросе пароля вводим: bandit0
💡 Важно: При вводе пароля в Linux символы не отображаются на экране — это нормально для безопасности.
Шаг 2: Исследование домашней директории
После успешного подключения видим приглашение:
bandit0@bandit:~$
ls -la
total 24
-rw-r-----   1 bandit1 bandit0  438 Sep 26 21:54 readme
drwxr-xr-x   2 root    root    4096 Sep 26 21:54 .
drwxr-xr-x 150 root    root    4096 Sep 26 21:58 ..
-rw-r--r--   1 root    root     220 Feb 13  2026 .bash_logout
-rw-r--r--   1 root    root    3851 Sep 26 21:38 .bashrc
-rw-r--r--   1 root    root     807 Feb 13  2026 .profile
Ключевое наблюдение:
Файл readme принадлежит пользователю bandit1 и группе bandit0
Права -rw-r----- означают: владелец может читать/писать, группа (мы) — только читать
Шаг 3: Чтение файла с паролем

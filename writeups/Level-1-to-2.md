Проблема: Файл называется - (дефис).
️ Решение
Почему cat - не работает?
В Linux дефис - используется для обозначения стандартного ввода (stdin). Если написать:
bash

cat -

Команда будет ждать, пока ты введёшь текст с клавиатуры, а не читать файл.
Решение: указать путь к файлу
Чтобы сказать системе "это файл в текущей директории", добавляем ./:
bash
cat ./-

## 📖 О проекте

**Bandit** — это wargame от OverTheWire, созданный для обучения основам безопасности Linux.  
Игра состоит из уровней, где каждый следующий уровень требует найти пароль от предыдущего.

**Цель:** Научиться работать с командной строкой Linux, понимать права доступа, скрытые файлы, специальные символы и базовые утилиты.

- **SSH клиент** — для подключения к серверу
